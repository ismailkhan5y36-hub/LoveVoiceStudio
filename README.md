# 🎙️ LoveVoice AI Studio (Global Multilingual Edition)

Production-grade Neural Text-to-Speech Web & Mobile Studio with **322+ ultra-realistic voices** across **76+ languages**.

- 🌐 **76+ Languages Supported:** Urdu (🇵🇰), Hindi (🇮🇳), Arabic (🇸🇦), Spanish (🇪🇸), English (🇺🇸), French (🇫🇷), German (🇩🇪), Chinese (🇨🇳), Japanese (🇯🇵), Turkish (🇹🇷), and 60+ more.
- ⚡ **Dual Synthesis Engines:**
  - **LoveVoice Global:** 322+ Microsoft Edge Neural HD voices (48kHz studio audio, ~1.0s generation).
  - **Kokoro Ultra:** 82M parameter deep-learning model with human breathing and emotional inflection.
- 📱 **Mobile & PWA Ready:** Installable directly as a native standalone app on Android & iOS.
- 📝 **Auto-Chunking:** Handles large scripts up to 30,000 characters seamlessly.
- 🎚️ **Fine Controls:** Speed / pacing adjustment (-50% to +50%), pitch tuning, and volume amplification.
- 💾 **Instant MP3 Export:** One-click download with timestamped history.
